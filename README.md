## Overview

This is a practice image project in Supervisely format where every image has one or two **audio references** attached: 20 images and 25 recordings, from a hot bulb engine and a blacksmith's anvil to a heartbeat, a tram and a tree frog chorus.

Open any image in the Image Labeling Toolbox and its recordings are listed in the **Audio** tab of the right sidebar, each with its own player, so you can listen while you label. The audio is reference only: it is never annotated and is not part of the annotation.

It is perfect for:

- **Trying audio references** — see how recordings attached to an image look and play in the labeling tool
- **Sound-assisted labeling** — label machines, vehicles or animals with the sound they make at hand
- **Learning the format** — see where audio references live in the image metadata (`meta.audio`)

The project has no classes, tags or annotations, so you can set up your own.

## How to Use This Project

Click **Get project** in the Ecosystem, or download the archive below and import it to your workspace as a Supervisely-format project. Then open any image and switch to the **Audio** tab.
